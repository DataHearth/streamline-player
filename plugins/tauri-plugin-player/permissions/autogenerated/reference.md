## Default Permission

Allows controlling the native player and listening to its events

#### This default permission set includes the following:

- `allow-capabilities`
- `allow-deviceInfo`
- `allow-frameRate`
- `allow-restoreDisplay`
- `allow-load`
- `allow-play`
- `allow-pause`
- `allow-seek`
- `allow-stop`
- `allow-speed`
- `allow-stats`
- `allow-subtitle`
- `allow-timing`
- `allow-voice`
- `allow-registerListener`
- `allow-register-listener`
- `allow-removeListener`
- `allow-remove-listener`
